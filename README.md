# Pulse - Fitness Tracker

Pulse is a fitness tracking web application built using HTML, CSS, and JavaScript. It helps users log their workouts, monitor daily activity, track water intake, set fitness goals, and keep track of their progress.

## Features

- Log and manage daily activities
- Track workouts using a built-in timer
- Monitor steps, calories, workout duration, and distance
- Track daily water intake
- Set daily and weekly fitness goals
- View weekly activity charts and insights
- Keep track of personal records
- Earn XP, level up, and unlock achievements
- Track activity streaks
- Customize your profile and switch between light and dark themes
- Save activity data and preferences using browser Local Storage

## Technologies Used

- HTML
- CSS
- JavaScript
- SVG graphics
- Local Storage

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

No backend setup is required.

## About the Project

Pulse was built to make fitness tracking simple and engaging. The project brings workout logging, hydration tracking, goal setting, and progress monitoring together in one interface.

Activity data is stored locally in the browser, so it is not automatically synchronized across devices.
